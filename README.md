# Kokoro TTS Scenario Reader v2

A high-quality script for synthesizing long text and structured scripts using the **Kokoro TTS** model and a **Gradio** web interface. 

This engine doesn't just pass text to the model; it features advanced audio post-processing and a custom tag parser to handle natural pauses, dynamic speed changes, and custom speech styling.

## ✨ Key Features

- **Custom Tag Parser:** Supports inline style markers like `[serious]`, `[calm]`, `[excited]` and dynamic pauses like `[short pause]`, `[long pause]`.
- **Advanced Audio Processing:** 
  - Automated adaptive punctuation-based pauses using randomized uniform distributions for a more human-like rhythm.
  - Efficient silence trimming (`trim_silence`) based on peak relative thresholds to remove artifacts.
  - Linear audio edge fading (`fade`) to completely eliminate digital clipping and clicks at chunk boundaries.
- **Smart Pipeline Initialization:** Lazy-loaded pipelines cached by language code (`'a'` for US, `'b'` for UK) to minimize RAM usage.
- **Dynamic Speed Variance:** Injected text-pacing variations (controlled via a "variation" slider) to add lively imperfections to the generative speech.
- **Clean UI:** Built with Gradio, featuring real-time synthesis progress tracking and zero text-length limits.

## 🛠️ Tech Stack

- **Core TTS:** `kokoro` (KPipeline)
- **Audio Processing:** `numpy`, `soundfile`
- **Interface:** `gradio`
- **Text Processing:** Python `re` (Regular Expressions)

## 🚀 How to Run

1. Install the required dependencies:
   ```bash
   pip install gradio numpy soundfile kokoro sounddevice
   ```
2. Run the application:
   ```bash
   python main.py
   ```
3. Open the local link generated by Gradio in your browser.
